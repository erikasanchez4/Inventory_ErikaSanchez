# Inventory Management System

Academic C# Windows Forms project created to practice inventory data management through a desktop interface.

## Project Overview

The application connects a Windows Forms interface to an inventory dataset and allows inventory records to be loaded, edited, and saved.

## Technologies

- C#
- .NET Windows Forms
- Data binding
- DataSet / TableAdapter

## Skills Demonstrated

- Desktop application development
- Working with structured data
- Data binding in Windows Forms
- Saving and updating records
- Event-driven programming

## Project Context

Academic project completed as part of my Information Systems coursework. It demonstrates foundational experience working with C# desktop applications and inventory data.
